# Repeated Trust Game과 사회불안/회피/철수의 관계 연구 — 통합 프로토콜

---

## 1. 연구 목적 및 가설

### 1.1 연구 목적

Repeated trust game에서 측정한 trust의 동태적 특성(초기 신뢰, 학습 속도, 배신 후 회복, 과신)이 사회불안·사회적 회피·철수와 어떻게 연결되는지 검증한다. 단순 "사회불안 → 낮은 trust" 수준을 넘어, 피드백 기반 trust updating의 비대칭성과 파트너 유형별 행동 분화를 핵심 분석 대상으로 삼는다.

### ㄷ1.2 가설

**H1 (Withdrawal/Low Trust):** 사회불안이 높을수록 초기 투자가 낮고, 전반적 투자 수준이 낮으며, 호혜적 상대에게도 trust를 충분히 형성하지 못한다.

**H2 (Unstable Trust Building):** 사회불안이 높을수록 trial-to-trial 투자 변동성이 크고, 특히 volatile partner 조건에서 과대반응이 두드러진다. 이는 긍정적 피드백에 대한 학습(positive updating)은 약하고 부정적 피드백에 대한 반응(negative updating)은 과도한 비대칭 패턴으로 나타난다.

**H3 (Over-trust/Self-protection Failure):** 사회불안이 높은 일부 하위군은 low reciprocity partner에게도 과도한 투자를 유지하며, 반복적 배신 이후에도 투자 감소가 불충분하다(자기보호 실패).

**H4 (매개 경로):** Parenting bonding style(PBI)이 attachment 불안/회피(ECR-R)를 경유하여 trust 행동에 영향을 미치며, attachment와 trust가 사회불안/회피/철수에 영향을 미친다. 이 효과는 우울, 일반불안, 외로움을 통제한 후에도 유지된다.

## 3. 실험 절차 (순서)

실험 순서는 설문을 과제 뒤에 배치하여 자기개념 기반의 행동 조정을 최소화한다. RTG tutorial은 RTG 규칙 학습용이므로 RTG 본실험 직전에 배치한다.

```
짧은 안내 및 동의 → 인구통계 수집
→ RTG Tutorial (trustee 역할 경험) → 이해도 점검
→ Repeated Trust Game 본실험
→ 설문 배터리
```

| 단계 | 내용 | 비고 |
|---|---|---|
| 1. 안내 및 동의 | 연구 목적 설명, 서면 동의 | deception 사용 시 IRB 범위 내 처리 |
| 2. 인구통계 | participant_id, age, sex_at_birth, gender, education, diagnosis, medication 등 | 1회 기록 |
| 3. RTG Tutorial | Trust game 규칙 학습 (참가자가 trustee 역할 경험) | 10 trials, 1 block; 분석 제외 |
| 4. 이해도 점검 | 배수, 반환 구조, 반복 상호작용 여부 확인 | 통과 필수 |
| 5. Repeated Trust Game 본실험 | 3개 partner × 15 trials = 45 trials | 핵심 과제 |
| 6. 설문 배터리 | 아래 5절 참조 | 과제 후 실시 |

## 4. 과제 설계

### 4.1 Repeated Trust Game (RTG)

#### 4.1.1 역할 및 구조

- 참가자는 항상 **trustor**
- 상대는 computerized agent이지만, 참가자에게는 "각기 다른 특성을 가진 상대"로 제시
- multiplier: ×3 (고정)

#### 4.1.2 Partner 유형 (3종)

| Partner type | 코드 | 평균 반환비율 | 변동성 구조 |
|---|---|---|---|
| High reciprocity | 1 | 0.60–0.75 | 낮은 분산 |
| Low reciprocity | 2 | 0.10–0.30 | 낮은 분산 |
| Volatile reciprocity | 3 | ~0.40 | 높은 분산 |

세 partner는 평균뿐 아니라 변동성 구조도 달라야 한다. Volatile partner는 단순히 평균이 중간인 것이 아니라 trial 간 반환비율이 큰 폭으로 변동하는 구조여야 "불안정한 trust building" 가설을 검증할 수 있다.

#### 4.1.3 Block 구조

- 한 block = 한 partner와 15 trials 연속 진행
- 총 3 blocks (partner별 1 block)
- Block 제시 순서: 참가자별 무작위화
- 각 block 종료 직후: Post-block perception 질문 실시

#### 4.1.4 Post-block Perception 질문

각 block 종료 직후 아래 세 문항을 수집한다.

1. **Partner 유형 분류:** "이 상대는 전반적으로 어떤 유형이었던 것 같은가?" (대체로 많이 돌려주는 편 / 대체로 적게 돌려주는 편 / 들쭉날쭉하고 예측하기 어려운 편)
2. **분류 확신도:** "그 판단에 대한 확신은 어느 정도인가?" (1–7 Likert)
3. **재참여 의향:** "이 상대와 다시 게임하고 싶은가?" (1–7 Likert)

이 질문의 기능: 행동 패턴만으로는 "합리적 학습에 기반한 전략적 저투자"와 "사회적 신호 해석 왜곡에 기반한 저투자"를 구분할 수 없다. Partner 인식 정확도와 확신도를 함께 보면 이 구분이 가능해진다.

## 7. 분석 계획

### 7.1 1차 분석: Trial-level Mixed-effects Model

```
amount_sent ~ trial_within_partner
              + partner_type
              + previous_return_ratio
              + social_anxiety (K-SIAS total)
              + K-BFNE total
              + PHQ-9 total
              + GAD-7 total
              + UCLA total
              + partner_type × social_anxiety
              + previous_return_ratio × social_anxiety
              + (1 + trial_within_partner | participant_id)
```

핵심 검정:
- social_anxiety 주효과 → H1 (전반적 저투자)
- social_anxiety × previous_return_ratio → H2 (피드백 반영 비대칭)
- social_anxiety × partner_type → H1, H2, H3 (partner 유형별 분화)

### 7.2 2차 분석: Participant-level Regression

participant-level 요약변수를 종속변수로 하는 다중 회귀:

- DV1: mean_sent_all_trials → H1
- DV2: discrimination_index → H1, H2
- DV3: instability_index_volatile_partner → H2
- DV4: overtrust_index_low_partner → H3

공통 독립변수: K-SIAS, K-SPS, K-BFNE

공통 공변량: PHQ-9, GAD-7, UCLA, age, sex_at_birth

### 7.3 3차 분석: 매개 모형 (H4)

경로 구조:

```
PBI (돌봄, 과보호)
   → ECR-R (애착불안, 애착회피)
      → RTG trust 행동지표 (mean_sent, discrimination_index 등)
         → 사회불안/회피/철수 (K-SIAS, K-SPS)
```

attachment와 trust 사이의 상관도 허용한다. 구조방정식 모형(SEM) 또는 Hayes PROCESS macro를 사용하며, 우울/범불안/외로움을 통제한 후 간접효과의 유의성을 bootstrap으로 검정한다.

### 7.4 보충 분석: Computational Modeling

Trial-by-trial Rescorla-Wagner 또는 hierarchical Bayesian 모형을 적용하여 개인별 잠재 파라미터를 추정한다.

추정 대상 파라미터:
- **α⁺ (positive learning rate):** 긍정적 피드백(호혜)에서의 학습 속도
- **α⁻ (negative learning rate):** 부정적 피드백(배신)에서의 학습 속도
- **prior trust (β₀):** 초기 신뢰 기대치
- **inverse temperature (β):** 선택의 확률적 정밀도

이렇게 추정된 파라미터를 2nd-stage regression에서 사회불안 점수 및 공변량과 연결한다.

예상 패턴:
- H1 군: β₀ 낮음, α⁺ 낮음
- H2 군: α⁻ 높음, α⁺ 낮음 (비대칭)
- H3 군: β₀ 높지만 α⁻ 낮음 (자기보호 실패)

## 8. 데이터 관리 원칙

1. Raw data는 덮어쓰지 않고 원본 보존한다.
2. 설문은 item-level과 total/subscale-level을 모두 저장한다.
3. RTG에서 매 trial마다 partner 정보, 투자액, 반환액, RT, algorithm log를 반드시 기록한다.
4. 파생변수는 분석 단계에서 재계산 가능하도록 원자료를 충분히 보존한다.
5. Tutorial/practice trial은 main_task_trial_flag로 구분한다.
6. 분석 제외 사유는 exclusion_reason에 텍스트로 기록한다.
7. Partner algorithm의 seed, version, schedule ID를 반드시 기록하여 완전한 재현성을 확보한다.
